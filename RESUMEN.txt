───────────────────────────────────────────────────────────────────────────
  ⚠️ SI HAY PROBLEMAS AL DESCARGAR
───────────────────────────────────────────────────────────────────────────

SÍNTOMAS:
  • Archivos de Vite presentes (index.html, vite.config.ts)
  • Carpeta src/ con app/ y components/ dentro
  • Error: "Cannot find module './app/page'"

SOLUCIÓN RÁPIDA:

  # 1. Ejecutar script de verificación
  chmod +x verify-structure.sh
  ./verify-structure.sh

  # 2. Si hay errores, leer documentación
  cat INSTRUCCIONES_DESCARGA.md

  # 3. Limpieza manual (si es necesario)
  rm index.html vite.config.*        # Eliminar archivos de Vite
  mv src/app ./                      # Mover app/ a raíz
  mv src/components ./               # Mover components/ a raíz
  rm -rf src/                        # Eliminar carpeta src/

  # 4. Instalar y ejecutar
  npm install
  npm run dev

  El archivo /App.tsx existe SOLO para compatibilidad con Figma Make.

  ¿Qué hacer con él?
